# 검토보고서 .dsd: 반기 ↔ 분기 서식 전환표

반기(2Q) 검토보고서에서 3분기(3Q) 검토보고서로 넘어갈 때 바꾸는 항목이다. 분기 → 반기로 갈 때는 이 표를 거꾸로 적용하고 전년 같은 분기 최종 dsd 와 골격을 비교한다(거꾸로는 아직 해 본 적 없음).

| 대상 | 반기(2Q) | 분기(1Q·3Q) |
|---|---|---|
| contents.xml DOCUMENT-NAME | `ACODE="90020">반기검토보고서` | `ACODE="90220">분기검토보고서` |
| meta.xml DOCUMENT-INFO | `bsn-id="11012" rpt-id="11012" doc-id="90020"` | `bsn-id="11013" rpt-id="11013" doc-id="90220"` |
| 라이브러리 이름 | `90020_H…`, `90020#*반기부속명세서_목차` | `90220_Q…`, `90220#*분기부속명세서_목차` |
| TABLE-GROUP ACLASS | `HBS-2:A`, `HIS-C2:A`, `HEF-1`, `HCF-IC:A` | `QBS-2:A`, `QIS-C2:A`, `QEF-1`, `QCF-IC:A` |
| 표 그룹 뒤 강조문 | 없음 | 각 재무제표 TABLE-GROUP 바로 뒤 `<EMPHASIS>&quot;검토를 받은 분기재무제표&quot;</EMPHASIS>` |
| AASSOCNOTE | `AASSOCNOTE="L-HCF"` 있음 | 삭제 |
| FILENAME | `01_반기재무상태표`, `07_반기손익계산서(분기보고대상이 아닌 경우)`, `20_반기자본변동표`, `16_반기현금흐름표-간접법` | `01_분기재무상태표`, `07_분기손익계산서`, `20_분기자본변동표`, `17_분기현금흐름표-간접법` |
| 제목 | `반 기 재 무 상 태 표`, `반   기   손   익   계   산   서` 등 | `분 기 재 무 상 태 표`, `분 기 손 익 계 산 서` 등, `(첨부)분 기 재 무 제 표`, 목차 `. 분기재무상태표 ---` |
| 기간 | `제 N (당)기 반기`, `제N(당)기 반기말`, `AUNITVALUE="YYYY0630"`, `YYYY년 06월 30일` | `제 N (당)기 3분기`, `제N(당)기 3분기말`, `YYYY0930`, `YYYY년 09월 30일` (전기도 같은 방식) |
| 검토 문단 | "반기재무제표를 검토하였습니다. 동 반기재무제표는 YYYY년 6월 30일 … 6개월 보고기간" | "3분기재무제표를 검토하였습니다. 동 분기재무제표는 YYYY년 9월 30일 현재의 재무상태표와 YYYY년 9월 30일과 전년 9월 30일로 종료되는 9개월 보고기간" |
| 라벨 | 당반기, 전반기, `VIII.반기순이익(손실)`, `1. 반기순이익(손실)`, 자본변동표 `반기순이익` | 당분기, 전분기, 분기순이익(손실) |
| 보호할 말 | "분ㆍ반기재무제표" 는 바꾸지 않음. 마지막에 남은 "반기" 가 "분ㆍ반기" 와 "일반기업"(정규식 `(?<!일)반기`) 뿐인지 확인 | |

## 비교 숫자
- 재무상태표 전기 = 전기말(직전 연도 12월 31일) 그대로
- 손익계산서·자본변동표·현금흐름표 전기 = 전년 같은 분기 누적. 전년 같은 분기 최종 보고서 숫자와 대조한다

## 검증
- XML 형식 오류 없음, 재무상태표 소계·총계·대차, 손익·현금흐름 합계, 기말현금 = 재무상태표 현금
- 서식 골격 태그(DOCUMENT-NAME, TABLE-GROUP, LIBRARYLIST, FILENAME, EMPHASIS, TITLE)가 전년 같은 분기 최종본과 같은지
- 사용자에게: DART 편집기에서 재무제표마다 표 안에 커서를 두고 F9 → 파일형식 검사

## 자리표시·판단 항목 (매 분기)
- 검토보고서일: 모르면 `YYYY년 MM월 ○일` 로 비우고 묻는다. 직전 보고서의 날짜를 반드시 바꾼다
- 기타사항 문단의 전기 감사보고서일
- 정산표에 없는 주석 금액(보험 부보금액 등)은 `확인필요` 로 넣고 보고
- 새 행(계정 등)이 생기면 보고에 명시
